Sogni Voice API Documentation

REST API for audio transcription and text-to-speech synthesis

Base URL: https://voice.sogni.ai

1. Voice Recording to Text (Transcription)

Upload an audio file and receive a text transcript.

POST /transcribe

Request

Send audio as multipart/form-data.

Parameter Type Description
file * File Audio file to transcribe (supports common formats: mp3, wav, webm, m4a, etc.)

Response

{
  "success": true,
  "transcript": "The transcribed text appears here.",
  "filename": "recording.mp3"
}

cURL Example

curl -X POST https://voice.sogni.ai/transcribe \
  -F "file=@/path/to/audio.mp3"

JavaScript Example

const formData = new FormData();
formData.append('file', audioFile);

const response = await fetch('https://voice.sogni.ai/transcribe', {
  method: 'POST',
  body: formData
});

const data = await response.json();
console.log(data.transcript);

Python Example

import requests

with open('audio.mp3', 'rb') as f:
    response = requests.post(
        'https://voice.sogni.ai/transcribe',
        files={'file': f}
    )

data = response.json()
print(data['transcript'])

2. Text to Speech (TTS)

Convert text to spoken audio. Returns a WAV audio file by default.

POST /tts

Request

Send JSON with the text and optional parameters.

Parameter Type Default Description
text * string - Text to convert to speech (1-10,000 characters)
voice (optional) string af_heart Voice to use (see /tts/voices for available voices)
speed (optional) number 1.0 Speech speed multiplier (0.5 to 2.0)
format (optional) string wav Output format: "wav", "opus" (returns audio file) or "buffer" (returns base64 JSON)
timestamps (optional) boolean false Include word-level timestamps for subtitle generation (forces JSON response)

Response (format: wav)

Returns binary WAV audio data with Content-Type: audio/wav

Response (format: buffer)

{
  "success": true,
  "audio": "UklGRiQAAABXQVZFZm10IBAA...",  // base64 encoded WAV
  "voice": "af_heart",
  "speed": 1.0,
  "format": "wav"
}

Response (with timestamps: true)

When timestamps is enabled, the response is always JSON and includes word-level timing data for subtitle generation:

{
  "success": true,
  "audio": "UklGRiQAAABXQVZFZm10IBAA...",  // base64 encoded audio
  "voice": "af_heart",
  "speed": 1.0,
  "format": "wav",
  "timestamps": [
    { "word": "Hello", "start": 0.000, "end": 0.312 },
    { "word": ",", "start": 0.312, "end": 0.440 },
    { "word": "world", "start": 0.440, "end": 0.752 },
    { "word": "!", "start": 0.752, "end": 0.880 }
  ]
}

Each timestamp object contains:

  • word - The word or punctuation token
  • start - Start time in seconds
  • end - End time in seconds

cURL Examples

# Save as WAV file
curl -X POST https://voice.sogni.ai/tts \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello, world!", "voice": "af_heart", "speed": 1.0}' \
  --output output.wav

# Get audio with word-level timestamps for subtitles
curl -X POST https://voice.sogni.ai/tts \
  -H "Content-Type: application/json" \
  -d '{"text": "Hello, world!", "voice": "af_heart", "timestamps": true}'

JavaScript Example

const response = await fetch('https://voice.sogni.ai/tts', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    text: 'Hello, world!',
    voice: 'af_heart',
    speed: 1.0
  })
});

// Get audio blob and play it
const audioBlob = await response.blob();
const audioUrl = URL.createObjectURL(audioBlob);
const audio = new Audio(audioUrl);
audio.play();

JavaScript Example (with timestamps for subtitles)

const response = await fetch('https://voice.sogni.ai/tts', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    text: 'Welcome to our video. Today we will learn something new.',
    voice: 'af_heart',
    timestamps: true
  })
});

const data = await response.json();

// Decode and play audio
const audioBytes = atob(data.audio);
const audioArray = new Uint8Array(audioBytes.length);
for (let i = 0; i < audioBytes.length; i++) {
  audioArray[i] = audioBytes.charCodeAt(i);
}
const audioBlob = new Blob([audioArray], { type: 'audio/wav' });
const audioUrl = URL.createObjectURL(audioBlob);
const audio = new Audio(audioUrl);

// Display subtitles synced to audio
audio.ontimeupdate = () => {
  const currentTime = audio.currentTime;
  const activeWords = data.timestamps.filter(
    t => currentTime >= t.start && currentTime < t.end
  );
  console.log('Current word:', activeWords.map(w => w.word).join(' '));
};

audio.play();

Python Example

response = requests.post(

Python Example (with timestamps for subtitles)

import requests
import base64

response = requests.post(
    'https://voice.sogni.ai/tts',
    json={
        'text': 'Welcome to our video. Today we will learn something new.',
        'voice': 'af_heart',
        'timestamps': True
    }
)

data = response.json()

# Save the audio file
audio_bytes = base64.b64decode(data['audio'])
with open('output.wav', 'wb') as f:
    f.write(audio_bytes)

# Generate SRT subtitle file
with open('subtitles.srt', 'w') as f:
    for i, ts in enumerate(data['timestamps'], 1):
        start = ts['start']
        end = ts['end']
        # Convert to SRT format (HH:MM:SS,mmm)
        start_str = f"{int(start//3600):02d}:{int((start%3600)//60):02d}:{int(start%60):02d},{int((start%1)*1000):03d}"
        end_str = f"{int(end//3600):02d}:{int((end%3600)//60):02d}:{int(end%60):02d},{int((end%1)*1000):03d}"
        f.write(f"{i}\n{start_str} --> {end_str}\n{ts['word']}\n\n")

print(f"Generated {len(data['timestamps'])} subtitle entries")

3. List Available Voices

Get a list of all available TTS voices.

GET /tts/voices

Response

{
  "voices": ["af_heart", "af_bella", "am_adam", ...],
  "default": "af_heart"
}

cURL Example

curl https://voice.sogni.ai/tts/voices
