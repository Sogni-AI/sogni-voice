## Phase 1: Compatibility

Check: `sw_vers && uname -m`
- If NOT arm64: stop, explain Apple Silicon required. Fallback: hosted https://voice.sogni.ai/ (testing only).

Check tools exist (don't install): `git --version; node -v; npm -v; brew --version; curl --version`
Report missing.

Check network: `curl -sS https://voice.sogni.ai/health || curl -sS -I https://voice.sogni.ai/`

## Phase 2: Install

Install dir: ~/repos/sogni-voice (if exists, ask user).

```
mkdir -p ~/repos && git clone https://github.com/Sogni-AI/sogni-voice.git ~/repos/sogni-voice
cd ~/repos/sogni-voice
brew install ffmpeg uv        # install Homebrew first if missing
npm install
./setup.sh --non-interactive  # localhost profile: Pocket TTS only + Parakeet enabled + AUTH disabled; predownloads enabled models to reduce cold-start latency
```

If users want additional TTS engines (Kokoro/Qwen), voice cloning setup, or API auth, tell them to run interactive setup manually:

```
./setup.sh
```

## Phase 3: Run & Verify

Start (pick one, confirm first):
- PM2 (recommended): `npm install -g pm2 && npm run pm2:start`
- Dev mode: `npm run dev`

Verify: `curl -sS http://localhost:3000/health`

Endpoints: GET /health, POST /tts, POST /transcribe, GET /tts/voices

Optional (ask first): `pm2 startup && pm2 save` for start-on-boot.

## Phase 4: Integrate with OpenClaw

Set OpenClaw TTS/STT base URL to http://localhost:3000. Test with a synthesize request. Summarize changes, paths, and start/stop commands (pm2 status/logs/restart/stop).
